    Plot resolution

    Adaptive preserves per-base detail for loci through 1,000 bases and otherwise uses the highest bounded display resolution.

    Effective resolution will appear after a query.

    Displayed range

    Run a query to enable range zoom.

    Select range enables horizontal dragging on either plot. Plot selections expand outward to the displayed bin boundaries; the exact TSV remains the full query.

    Adaptive uses one display bin per base through 1,000 bases, then the bounded maximum of 1,000 bins, preserving the strongest available detail without unbounded SVG growth. Cs itself is per-base; SNP density remains the archived centred 20-bp rolling statistic, and CNEr evidence remains derived from 30/50-bp source windows. Finer display subdivision does not add biological resolution. Hover for query values; range zoom and the optional overlapping-gene tracks re-render retained full-query data without another genomic request. Additional loci use one representative transcript per overlapping gene; the queried gene retains its selected or complete isoform display. Transcript labels link to the matching VectorBase gene record in a new tab. The exact TSV retains every queried base and species row, while SVG downloads use the active displayed range, annotation choice, and resolution.

    Accessibility/QC
    Separate companion track

    Browser query limit: 200,000 bases. This engineering ceiling is not a biological threshold: it supports 13,080 of 13,097 indexed genes (99.8702%); the 17 longer genes remain available through the CLI. The versioned index covers AGAP genes and transcript isoforms on 2L, 2R, 3L, 3R, and X; official gene symbols come from a separately versioned AgamP4 naming index. Failed accessibility/QC positions are shown separately as unknown.

    How to read the results

    Conservation and data quality are shown separately.

    Conservation score

    The blue profile summarizes Cs across the displayed interval. Ribbons show within-bin variation rather than measurement uncertainty.

    SNP density

    Green is the archived 20 bp sliding-window SNP density. It is shown unchanged where quality allows interpretation.

    Unknown positions

    Grey positions failed the accessibility mask. They are unknown—not confirmed invariant and not zero-density evidence.

    Project and people

    Open research software, developed in a scientific setting.

    AgamCs was created to make conservation evidence around Anopheles gambiae genes easier to inspect, compare, and export. The project keeps its code, scientific provenance, quality-control semantics, and feedback process public.
